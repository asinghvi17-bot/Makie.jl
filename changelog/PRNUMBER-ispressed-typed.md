## Changed

- `ispressed` is now a single method that branches on the type of the button (`Bool`, `Keyboard.Button`, `Mouse.Button`, `And`, `Or`, `Not`, `Exclusively`, and `Tuple`, `Vector` and `Set` of those) instead of one method per type. A button read from an `Observable{IsPressedInputType}` or an `Any`-typed attribute is therefore a call with a single candidate method, which type inference returns as `Bool`. This removes the dynamic dispatch on `ispressed` that ahead-of-time compilation (`juliac --trim`, WasmCodegen) cannot compile. A `Vector` or `Set` of buttons or of operators of buttons (`Keyboard.Button`, `Mouse.Button`, `Union{Keyboard.Button, Mouse.Button}`, `Enum{Int32}`, `Bool`, `Any`, `BooleanOperator`, `Exclusively` and `And`, `Or`, `Not` of the two button types) is found by `isa` and iterated with its concrete type, so these compile statically too, also when read from an `Observable{IsPressedInputType}` or `Any`. Collections are iterated as before, whatever their element type (there is no change for collections themselves); other element types go through `Makie._ispressed_collection_fallback`. That function is the one dynamic call that is left and that a static build can't compile; WasmCompat's Makie extension replaces it in a Wasm build, where it throws an `ArgumentError` naming the unsupported collection type. The behaviour changes that come with the single method:
  - A button type that `ispressed` does not know, also one inside an `And`, `Or`, `Not` or a collection, now throws an `ArgumentError` instead of a `MethodError`.
  - Elements of operators and collections that are not one of the types above are evaluated with `ispressed(parent, element, waspressed)`, so methods that are added to `ispressed` for other types keep working there, and must accept the `waspressed` argument. Methods that are added for the types above (e.g. a method for `Keyboard.Button` or `Vector{Keyboard.Button}`) are still used when `ispressed` is called with that type directly, but are no longer used for elements of operators and collections.
  - `ispressed(parent, Exclusively(...), waspressed)` with a button as `waspressed` no longer errors.
